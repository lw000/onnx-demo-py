压缩机泄漏检测模型中，正常状态与泄漏状态与输入特征（pressure、supply_flow、demand_flow）的关系分析如下：
# 核心判定逻辑
模型的核心原理是质量守恒定律：在封闭系统中，供气量应等于用气量。
正常状态：supply_flow ≈ demand_flow
泄漏状态：supply_flow > demand_flow （差值即为泄漏量）
输入特征与状态的详细关系分析

## 1. supply_flow (供气流量) 与 demand_flow (用气流量)
这两个参数是模型判定的核心依据，它们的差值模式决定了输出结果。
| 状态 | `supply_flow` (供气) | `demand_flow` (用气) | 关系分析 |
| :--- | :--- | :--- | :--- |
| 正常 | 随负载波动 | 随负载波动 | 两者高度同步。当用气设备开启时，用气量上升，压缩机加载，供气量随之上升。两者数值在误差范围内基本平衡。 |
| 泄漏 | 持续偏高或维持高位 | 偏低或波动较小 | 两者出现显著偏差。即使下游用气设备关闭（`demand_flow` 接近 0），压缩机为了维持压力仍在运行，导致 `supply_flow` 依然有读数。此时 `supply_flow` 显著大于 `demand_flow`，差值部分即为泄漏掉的空气。 |


## 2. pressure (供气压力)
压力是系统密封性和压缩机控制逻辑的直接反映，虽然模型主要通过流量差判定，但压力特征起到重要的辅助验证作用。
| 状态 | `pressure` 特征表现 | 关系分析 |
| :--- | :--- | :--- |
| 正常 | 稳定在设定范围内 | 压力通常维持在压缩机的加载/卸载压力带之间（例如 0.7-0.8 MPa）。当用气量增加时，压力可能会短暂下降，随后因压缩机加载而恢复。 |
| 泄漏 | 难以维持或频繁波动 | - 小泄漏：压力可能正常，但压缩机会比平时更频繁地加载（为了补偿泄漏量），导致 `supply_flow` 平均值偏高。<br>- 大泄漏：如果泄漏量超过了压缩机的产气能力，系统压力将持续下降，无法达到设定的停机压力，导致压缩机长期高负荷运行。 |



# 故障特征总结表
| 输入特征 | 正常状态表现 | 泄漏状态表现 | 判定逻辑关键词 |
| :--- | :--- | :--- | :--- |
| `supply_flow` | 跟随 `demand_flow` 变化 | 虚高（包含泄漏量） | 差值过大 |
| `demand_flow` | 跟随生产工况变化 | 正常或偏低（相对于供气） | 供需不平衡 |
| `pressure` | 稳定，波动符合控制逻辑 | 下降快，恢复慢，或频繁加卸载 | 压力异常 |

# 模型训练与推理建议
关注差值特征：虽然模型输入是三个独立特征，但在实际物理意义上，模型实际上是在学习 supply_flow - demand_flow 这个差值的分布。
排除瞬态干扰：在储气罐充放气的瞬间，供气和用气流量会有短暂的不平衡（气体压缩/膨胀效应），模型（特别是决策树）需要通过 max_depth 限制来忽略这些正常的瞬态波动，只关注持续性的流量差。
